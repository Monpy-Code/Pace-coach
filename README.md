# 🏃 페이스 코치 (Pace Coach)

목표 대회까지 **D-Day를 세고, 그날까지의 주간 훈련을 자동으로 짜주는** 모바일 우선 웹 앱(PWA)입니다.
삼성헬스 캡처를 올리면 **API 키 없이도** 브라우저 안에서 숫자를 읽어 기록을 채우고(무료 OCR), 저장하는 순간 훈련 페이스와 예상 완주 기록이 다시 계산됩니다.

- 순수 정적 파일 (HTML/CSS/JS, 빌드 없음) → GitHub Pages 등 아무 정적 호스팅에나 그대로 올릴 수 있습니다.
- 데이터는 브라우저 `localStorage`에만 저장됩니다. 서버·계정 없음.

## 파일 구성

```
apps/pace-coach/
├── index.html                        화면 뼈대 · PWA 메타태그
├── styles.css                        다크/스포티 UI (390px 모바일 기준, 430px까지 확장)
├── app.js                            상태·계산·렌더링 전부 (프레임워크 없음)
├── manifest.json                     PWA 매니페스트 (standalone, 아이콘 3종)
├── sw.js                             서비스 워커 (네트워크 우선 + 오프라인 캐시)
├── README.md
└── assets/
    ├── icon-192.png / icon-512.png / icon-180.png / icon-maskable-512.png
    └── samsung-health-sample.svg     '캡처 인식 체험'용 샘플 삼성헬스 화면
```

## 로컬에서 열기

```bash
cd apps/pace-coach
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`index.html`을 파일로 직접 열어도 대부분 동작하지만, 서비스 워커와 PWA 설치는 `http(s)`에서만 동작합니다.

## GitHub Pages에 올리기

1. 이 폴더를 저장소 루트(또는 `docs/`)에 둡니다.
2. GitHub → Settings → Pages → Source: `Deploy from a branch` → `main` / `/ (root)`.
3. 잠시 후 `https://<계정>.github.io/<저장소>/` 에서 열립니다. (모든 경로가 상대경로라 하위 경로 배포도 그대로 동작)
4. 갤럭시 Chrome에서 열고 **⋮ → 앱 설치(홈 화면에 추가)** → 아이콘으로 실행하면 주소창 없는 앱처럼 뜹니다.

## 캡처 자동 인식 (v1.2)

이미지를 고르면 **자동으로 인식이 시작**되고, 결과 카드에서 바로 저장할 수 있습니다.

| 모드 | 조건 | 동작 |
|---|---|---|
| **무료 내장 OCR** (기본) | API 키 없음 | `Tesseract.js v5`(eng 모델)를 이미지를 고를 때 lazy-load. 2~4배 업스케일 → 흑백·대비 강조(다크 화면은 자동 반전) → 숫자·단위 인식. 실패한 칸은 비워 두고 “못 읽은 칸만 손으로 채워 주세요” 안내 |
| **AI Vision** (선택) | 설정에 키 있음 | Claude/OpenAI Vision이 더 꼼꼼히 읽고 코칭 문장까지 생성. 호출이 실패하면 무료 OCR로 자동 전환 |

- 삼성헬스 러닝 상세 화면의 큰 거리(`5.02 km`), `운동 시간 29:46`, `평균 페이스 05'55"`, `평균 심박수 156 bpm`, `평균 케이던스 171 spm`, 날짜(`2026. 11. 18.` / `2026년 11월 18일`)를 단위·글자 크기·좌표 맥락으로 구분해 읽습니다. 페이스가 안 읽히면 거리÷시간으로 계산합니다.
- "📸 캡처 다시 읽기"로 재인식할 수 있고, 인식된 요약·코치 문장과 함께 "이 내용으로 바로 저장" 버튼이 붙습니다.
- OCR 엔진·학습데이터는 서비스 워커가 캐시하므로 한 번 받은 뒤에는 오프라인에서도 동작합니다.

## AI 캡처 인식 (선택)

설정 → **AI 코치 연동**에서 제공사를 고르고 API 키를 넣으면, 이미지를 올릴 때 Vision API로
날짜 · 거리 · 시간 · 평균 페이스 · 평균 심박 · 케이던스를 읽어 폼을 채우고 코칭 문장을 만들어 줍니다.

| 제공사 | 엔드포인트 | 비고 |
|---|---|---|
| Claude (Anthropic) | `POST api.anthropic.com/v1/messages` | `anthropic-dangerous-direct-browser-access: true` 헤더로 브라우저 직접 호출. 오류 응답까지 CORS 허용되어 안내가 정확합니다. |
| OpenAI | `POST api.openai.com/v1/chat/completions` | 브라우저 직접 호출은 CORS 정책에 따라 차단될 수 있습니다(실패 시 앱이 안내 문구 표시). |

- 키는 **이 브라우저의 localStorage에만** 저장되고, 중간 서버 없이 브라우저에서 해당 제공사로만 전송됩니다.
- 기본 모델: Claude `claude-sonnet-4-5`, OpenAI `gpt-4o-mini` (설정에서 변경 가능).
- **JSON 내보내기에는 키가 포함되지 않습니다.** 공용 기기에서는 사용 후 키를 삭제하세요.
- 키가 없으면 앱은 수기 입력 모드로 동작합니다: 숫자를 넣으면 페이스가 자동 계산되고, **샘플 캡처 인식 체험** 버튼으로 AI 인식 흐름을 미리 볼 수 있습니다.

## 훈련 계획은 이렇게 계산됩니다

| 항목 | 방식 |
|---|---|
| 현재 실력(10K 환산) | 최근 8주 기록을 Riegel 공식 `T₂ = T₁ × (D₂/D₁)^1.06` 으로 10K 환산해 가장 좋은 값 사용. 기록이 없으면 목표 기록 × 1.06 |
| 컨디션 보정 | 최근 7일 기록에 '무릎 뻐근함' +4%, '피로 누적' +2% (예상 기록을 보수적으로) |
| 강도 자동 하향 | 위 신호가 있으면 **이번 주** 인터벌·템포·LSD(무릎은 이지런까지)를 회복런으로 대체 |
| 페이스 존 | 10K 페이스 기준: 회복 +85s, 이지 +50s, 장거리 +60s, 템포 −10s, 인터벌 −32s (초/km) |
| 주간 볼륨 | 종목별 기본치(5K 18 / 10K 26 / 하프 40 / 풀 58 km) × 주차별 최대 +12% |
| 요일 배치 | 월 휴식·보강 / 화 인터벌 / 수 이지 / 목 템포 / 금 휴식 / 토 장거리 / 일 회복 |
| 테이퍼링 | 대회 7일 전부터 볼륨 축소 · 인터벌 제거 · '페이스 리허설'로 대체 |
| 심박 존 | 설정의 최대심박(기본 174bpm = 47세 추정치) 기준 %구간 |

## 자동 진단 · 실전 코칭 (v1.1)

기록을 저장하면(수기 입력·캡처 인식 모두) 숫자에서 바로 읽어낸 **진단 배지와 코칭 문장**이 기록 카드에 붙습니다.

| 진단 | 조건 | 표시되는 코칭 |
|---|---|---|
| **오버페이스** | 그날 계획이 이지·회복·장거리인데 **계획 페이스보다 20초/km 이상 빠르게** 뛴 경우 | “계획(회복런 6'53"~7'13")보다 55초/km 빠르게 뛰셨어요! 쉬운 날이 없으면 무릎 회복이 안 돼요. 다음 회복런은 …” 처럼 실제 초수와 다음 목표 페이스를 함께 제시 |
| **케이던스 낮음** | `cadence < 165` spm | “보폭이 길어 무릎 충격이 커질 수 있어요. 메트로놈 168~172 BPM에 맞춰 보폭을 줄여 보세요” |
| **손목 심박 의심** | `pace ≤ 6'45"/km` 인데 `평균 심박 < 125bpm` | “빠른 페이스 대비 심박이 낮게 찍혔어요(손목 센서 오측정 가능성). 숫자보다 '옆사람과 문장으로 대화 가능한지' 체감 강도로 판단하세요” |

오버페이스 판단 기준은 그날의 실제 계획입니다. 컨디션 신호로 회복런까지 내려간 주라면 회복런 페이스가 기준이 되고, 이번 주 이전 기록은 요일 템플릿(수 이지·일 회복·토 장거리)으로 되돌아가 판단합니다. 인터벌·템포·리허설·레이스가 계획된 날은 진단 대상이 아닙니다.

### 휴식일 · 장거리 코칭

- **휴식 · 보강 카드**: 무릎 보호용 중둔근·코어 루틴을 함께 보여줍니다 — 힙 브리지 12회×3 · 밴드 사이드 스텝 15보×3 · 클램쉘 20회×3 · 플랭크 45초×3. “스쿼트 등 깊은 무릎 굴곡은 통증 시 제외” 주의 문구 포함.
- **12km 이상 장거리(LSD) 카드**: “9분 달리기 + 1분 걷기(런-워크) 권장”, “첫 1km는 의도적으로 느리게” 팁이 붙습니다. (10km 종목의 장거리가 9km 수준일 때는 기본 안내만)
- **연속 러닝 금지**: 어제 러닝 기록이 있는데 오늘이 인터벌·템포·장거리·리허설이면 오늘 카드에 **‘연속 러닝 주의’** 배지와 “어제 달리셨으니 오늘은 휴식·보강으로 미루고 내일 뛰는 걸 권장해요” 안내가 붙습니다. 오늘 꼭 뛰어야 할 때의 대체 강도도 함께 제안합니다.

## 한계

- 기록은 삼성헬스 캡처(무료 OCR·Vision) 또는 수기 입력만 지원합니다(연동 API 없음).
- 무료 OCR은 `eng` 모델만 쓰므로 한글 라벨은 읽지 않고, 숫자·단위(`km`·`bpm`·`spm`)·시간 형식으로 값을 구분합니다. 글자가 작거나 잘린 캡처에서는 일부 값이 비어 있을 수 있습니다.
- 계획은 러닝 생리학의 일반 원칙을 단순화한 규칙 기반이며, 의료 조언이 아닙니다. 통증이 지속되면 전문가와 상담하세요.
- 예상 기록은 최근 기록 1건(Riegel) 기반이라 기록이 적으면 오차가 큽니다. 기록이 쌓일수록 정확해집니다.
