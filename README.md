# 🏃 페이스 코치 (Pace Coach)

목표 대회까지 **D-Day를 세고, 그날까지의 주간 훈련을 자동으로 짜주는** 모바일 우선 웹 앱(PWA)입니다.
삼성헬스 캡처를 올리면 (키를 넣은 경우) AI가 숫자를 읽어 기록을 채우고, 저장하는 순간 훈련 페이스와 예상 완주 기록이 다시 계산됩니다.

- 순수 정적 파일 (HTML/CSS/JS, 빌드 없음) → GitHub Pages 등 아무 정적 호스팅에나 그대로 올릴 수 있습니다.
- 데이터는 브라우저 `localStorage`에만 저장됩니다. 서버·계정 없음.

## 파일 구성

```
apps/pace-coach/
├── index.html                        화면 뼈대 · PWA 메타태그
├── styles.css                        다크/스포티 UI (390px 모바일 기준, 430px까지 확장)
├── app.js                            상태·계산·렌더링 전부 (프레임워크 없음)
├── manifest.json                     PWA 매니페스트 (standalone, 아이콘 3종)
├── sw.js                             서비스 워커 (네트워크 우선 + 오프라인 캐시)
├── README.md
└── assets/
    ├── icon-192.png / icon-512.png / icon-180.png / icon-maskable-512.png
    └── samsung-health-sample.svg     '캡처 인식 체험'용 샘플 삼성헬스 화면
```

## 로컬에서 열기

```bash
cd apps/pace-coach
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`index.html`을 파일로 직접 열어도 대부분 동작하지만, 서비스 워커와 PWA 설치는 `http(s)`에서만 동작합니다.

## GitHub Pages에 올리기

1. 이 폴더를 저장소 루트(또는 `docs/`)에 둡니다.
2. GitHub → Settings → Pages → Source: `Deploy from a branch` → `main` / `/ (root)`.
3. 잠시 후 `https://<계정>.github.io/<저장소>/` 에서 열립니다. (모든 경로가 상대경로라 하위 경로 배포도 그대로 동작)
4. 갤럭시 Chrome에서 열고 **⋮ → 앱 설치(홈 화면에 추가)** → 아이콘으로 실행하면 주소창 없는 앱처럼 뜹니다.

## AI 캡처 인식 (선택)

설정 → **AI 코치 연동**에서 제공사를 고르고 API 키를 넣으면, 이미지를 올릴 때 Vision API로
날짜 · 거리 · 시간 · 평균 페이스 · 평균 심박 · 케이던스를 읽어 폼을 채우고 코칭 문장을 만들어 줍니다.

| 제공사 | 엔드포인트 | 비고 |
|---|---|---|
| Claude (Anthropic) | `POST api.anthropic.com/v1/messages` | `anthropic-dangerous-direct-browser-access: true` 헤더로 브라우저 직접 호출. 오류 응답까지 CORS 허용되어 안내가 정확합니다. |
| OpenAI | `POST api.openai.com/v1/chat/completions` | 브라우저 직접 호출은 CORS 정책에 따라 차단될 수 있습니다(실패 시 앱이 안내 문구 표시). |

- 키는 **이 브라우저의 localStorage에만** 저장되고, 중간 서버 없이 브라우저에서 해당 제공사로만 전송됩니다.
- 기본 모델: Claude `claude-sonnet-4-5`, OpenAI `gpt-4o-mini` (설정에서 변경 가능).
- **JSON 내보내기에는 키가 포함되지 않습니다.** 공용 기기에서는 사용 후 키를 삭제하세요.
- 키가 없으면 앱은 수기 입력 모드로 동작합니다: 숫자를 넣으면 페이스가 자동 계산되고, **샘플 캡처 인식 체험** 버튼으로 AI 인식 흐름을 미리 볼 수 있습니다.

## 훈련 계획은 이렇게 계산됩니다

| 항목 | 방식 |
|---|---|
| 현재 실력(10K 환산) | 최근 8주 기록을 Riegel 공식 `T₂ = T₁ × (D₂/D₁)^1.06` 으로 10K 환산해 가장 좋은 값 사용. 기록이 없으면 목표 기록 × 1.06 |
| 컨디션 보정 | 최근 7일 기록에 '무릎 뻐근함' +4%, '피로 누적' +2% (예상 기록을 보수적으로) |
| 강도 자동 하향 | 위 신호가 있으면 **이번 주** 인터벌·템포·LSD(무릎은 이지런까지)를 회복런으로 대체 |
| 페이스 존 | 10K 페이스 기준: 회복 +85s, 이지 +50s, 장거리 +60s, 템포 −10s, 인터벌 −32s (초/km) |
| 주간 볼륨 | 종목별 기본치(5K 18 / 10K 26 / 하프 40 / 풀 58 km) × 주차별 최대 +12% |
| 요일 배치 | 월 휴식·보강 / 화 인터벌 / 수 이지 / 목 템포 / 금 휴식 / 토 장거리 / 일 회복 |
| 테이퍼링 | 대회 7일 전부터 볼륨 축소 · 인터벌 제거 · '페이스 리허설'로 대체 |
| 심박 존 | 설정의 최대심박(기본 174bpm = 47세 추정치) 기준 %구간 |

## 한계

- 기록은 삼성헬스 캡처 또는 수기 입력만 지원합니다(연동 API 없음).
- 계획은 러닝 생리학의 일반 원칙을 단순화한 규칙 기반이며, 의료 조언이 아닙니다. 통증이 지속되면 전문가와 상담하세요.
- 예상 기록은 최근 기록 1건(Riegel) 기반이라 기록이 적으면 오차가 큽니다. 기록이 쌓일수록 정확해집니다.
